# Workflow approved identity and asset handling

- Workflow_Brand_Reference.png is the image supplied by the founder and is the canonical direction.
- Workflow_Standalone_W.png is a separately generated transparent-background interpretation of the approved W; check geometry against the canonical reference before production.
- Workflow_App_Icon_Reference.png is a separately generated dark navy app-icon interpretation; it has presentation-space margins and is NOT a ready-to-ship favicon.
- Canonical colors visible in approved brand board: midnight #0B1F3B; electric blue #3B82F6; teal #14B8A6; white #FFFFFF.
- The exact logo font is NOT extractable with confidence from a flattened PNG. Request original SVG/AI/Figma and font info; use canonical wordmark art rather than substituting a guessed font. Manrope is a suggested companion for UI and text only.
- Have a designer create/verify real SVG/vector artwork and proper icon exports from approved source before launch. Do not present PNG tracing as an official vector master.

- `Workflow_W_Transparent_*.png` / `Workflow_App_Tile_*.png` and monochrome versions are derived preview exports from the separately generated icon; please compare them visually to the original approved board and replace with verified source-SVG exports before brand sign-off.
